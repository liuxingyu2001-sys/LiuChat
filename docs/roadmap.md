## 验收计划

真实代理和客户端验收不在开发机单元测试中冒充完成。完整环境、测试矩阵、客户端检查项、失败定位、发布门禁和结果模板见 [端到端验收](e2e-acceptance.md)。执行前可用只读预检：

```bash
scripts/e2e/check-environment.sh --help
```

预检只检查环境和静态配置，不能替代客户端登录、代理转发和双后端运行验收。
